# دستیار هوشمند مسیر‌یابی نابینایان

اپلیکیشن اندرویدی فارسی برای کمک به کاربران نابینا در شناخت محیط، دریافت اطلاعات مکانی و راهنمایی صوتی.

## هدف نسخهٔ اولیه
- سازگاری با TalkBack و رابط فارسی
- بررسی قابلیت‌های واقعی گوشی در زمان اجرا
- آزمایش GPS، دوربین و حسگرهای موجود
- طراحی ماژولار برای توسعهٔ تدریجی
- اجرای سبک روی Samsung Galaxy A12 با رم ۴ گیگابایت

## اصول ایمنی
این برنامه جایگزین عصای سفید، راهنمای انسانی یا روش‌های ایمن حرکت نیست. تشخیص موانع و موقعیت‌یابی ممکن است خطا یا تأخیر داشته باشد.

## وضعیت توسعه
در مرحلهٔ آماده‌سازی مخزن و تعریف ساختار اولیه.

## فناوری‌های برنامه‌ریزی‌شده
- Kotlin و ابزارهای بومی اندروید
- Git و GitHub برای مدیریت کد
