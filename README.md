# دستیار هوشمند مسیریابی نابینایان (نسخه سبک)

برنامه اندرویدی فارسی، سازگار با TalkBack. پیش‌فرض برای Samsung Galaxy A12.

**هشدار ایمنی:** این برنامه جایگزین عصای سفید یا روش‌های ایمن حرکت نیست.

## ساختار
- `core`: تشخیص قابلیت‌های گوشی، تنظیمات، ثبت خطا
- `speech`: گفتار فارسی
- `location`: GPS
- `compass`: قطب‌نما و جایگزین GPS
- `camera`: گرفتن عکس
- `ai`: رابط تحلیل تصویر، تحلیل محلی، سرور، و مسیریاب پردازش
- `ui`: صفحه اصلی و تنظیمات

## ساخت
با هر push، GitHub Actions فایل APK را می‌سازد و در بخش Releases با نام latest قرار می‌دهد.
